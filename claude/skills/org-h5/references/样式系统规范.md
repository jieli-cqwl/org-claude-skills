# 样式系统规范

> 基于 qft-harmonyos-vue3 项目实际代码统计

## 颜色变量（uni.scss）

### 品牌色

| 变量 | 色值 | 用途 |
|------|------|------|
| `$text-blue` | #3277FF | 主色、链接、按钮文字 |
| `$bgc-blue` | #3377FF | 主按钮背景 |
| `$text-blue-light` | #E8F0FF | 浅蓝背景、选中态 |

### 中性色

| 变量 | 色值 | 用途 |
|------|------|------|
| `$text-black` | #333333 | 主要文字 |
| `$text-grey` | #84888F | 次要文字（最常用） |
| `$text-grey-light` | #999999 | 辅助文字、placeholder |
| `$bgc-page` | #F1F2F7 | 页面背景 |
| `$bgc-grey` | #84888F | 特殊标签灰色背景 |
| `$bgc-grey-text` | #EAEDF2 | 灰色字体的背景 |
| `$bgc-white` | #FFFFFF | 卡片背景 |

### 功能色

| 变量 | 色值 | 用途 |
|------|------|------|
| `$text-red` | #ED184E | 错误、必填、价格 |
| `$bgc-red-type-one` | #FF3D6E | 警告按钮 |
| `$bgc-red-type-two` | #FFE0E6 | 浅红背景 |
| `$bgc-red-type-three` | #FBBCCC | 中红背景 |
| `$text-orange` | #FF6A00 | 警告提示 |
| `$bgc-orange` | #FF6A00 | 橙色背景 |
| `$text-yellow` | #D5B62B | 黄色文字 |
| `$bgc-yellow` | #FAD955 | 黄色背景 |
| `$text-special-blue` | #22ADE3 | 短租标签等特殊蓝 |
| `$bgc-special-blue-type-one` | #22ADE3 | 特殊蓝背景 |
| `$bgc-special-blue-type-two` | #e9f5fa | 浅特殊蓝背景 |

### 边框色

| 变量 | 色值 | 用途 |
|------|------|------|
| `$border-grey` | #E5E5E5 | 常规边框 |
| `$border-grey-light` | #F0F0F0 | 浅色分割线 |

## 间距（rpx）

| 值 | 占比 | 场景 |
|----|------|------|
| 20rpx | 34% | 常用间距、列表项 |
| 32rpx | 20% | 页面边距、卡片内边距 |
| 24rpx | 12% | 中等间距 |
| 16rpx | 10% | 小间距、图标与文字 |
| 8rpx | 6% | 紧凑间距 |
| 40rpx | 4% | 大间距、区块分隔 |

## 字体

| 字号 | 用途 |
|------|------|
| 24rpx | 辅助说明、标签、时间 |
| 28rpx | 正文（默认） |
| 32rpx | 小标题、列表项标题 |
| 36rpx | 卡片标题 |
| 40rpx | 页面标题 |
| 48rpx | 大数字、金额 |

字重：400 正文 / 500 小标题 / 600 标题

## 圆角

| 值 | 用途 |
|----|------|
| 6rpx | 输入框、小按钮 |
| 8rpx | 卡片、按钮（最常用） |
| 12rpx | 大卡片、弹窗 |
| 46rpx | 胶囊按钮 |
| 50% | 圆形头像 |

## 阴影

| 场景 | 值 |
|------|-----|
| 卡片 | `0 2rpx 12rpx rgba(0,0,0,0.08)` |
| 浮层 | `0 -4rpx 20rpx rgba(0,0,0,0.12)` |
| 按钮 | `0 4rpx 12rpx rgba(50,119,255,0.3)` |
