# 项目初始化规范

## 创建项目

- HBuilderX：新建 → uni-app → Vue3 + TypeScript
- CLI：`npx degit dcloudio/uni-preset-vue#vite-ts my-project`

## 必装依赖

```bash
npm install pinia@2.0.35 sass sass-loader z-paging
```

## easycom 配置（pages.json）

```json
{
  "easycom": {
    "autoscan": true,
    "custom": {
      "^comp-(.*)": "@/components/comp-$1/comp-$1.vue",
      "^(?!z-paging-refresh|z-paging-load-more)z-paging(.*)": "z-paging/components/z-paging$1/z-paging$1.vue",
      "^uni-(.*)": "@dcloudio/uni-ui/lib/uni-$1/uni-$1.vue"
    }
  }
}
```

## Pinia 注册（main.ts）

```typescript
import { createSSRApp } from "vue"
import { createPinia } from 'pinia'
export function createApp() {
  const app = createSSRApp(App)
  app.use(createPinia())
  return { app }
}
```

## uni.scss 全局变量

颜色/间距/字体/圆角变量 → 见「样式系统规范.md」

## manifest.json（H5）

```json
{
  "h5": {
    "router": { "mode": "hash", "base": "./" },
    "devServer": { "port": 8080, "proxy": { "/api": { "target": "http://localhost:3000", "changeOrigin": true } } }
  }
}
```

## 开发命令

| 命令 | 平台 |
|------|------|
| `npm run dev:h5` | H5 开发 |
| `npm run dev:mp-weixin` | 微信小程序 |
| `npm run build:h5` | H5 构建 |
| `npm run build:mp-weixin` | 小程序构建 |
