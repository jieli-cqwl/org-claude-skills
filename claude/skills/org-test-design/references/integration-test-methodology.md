# 集成测试展开规则

> 引用者：`test-design/SKILL.md` 步骤 6。

## 必须展开条件

- 跨模块流程
- 跨服务调用
- 异步 / MQ / 事件驱动
- 依赖事务一致性
- 外部依赖交互

## 常见展开信号

- 一条 AC 需要多个边界协同完成
- 设计里出现“编排流程 / 聚合流程 / 回调流程”
- 单接口成功依赖多个下游返回

## 不确定时的保守展开

- 若一个 AC 依赖多个边界协同完成，至少补 1 个端到端集成场景。

## 最小用例方向

- 模块间接口正确传递（输入/输出/错误）
- 关键数据链路端到端一致
- 关键异常链路（超时/失败/重试）可观测
