# 性能效率

> `rules/代码规范.md` 定义代码约束规则；本文件定义性能与资源效率要求。

## 核心要点

| 维度 | 要求 |
|------|------|
| 增量 | 优先增量处理，记录已处理状态，避免全量重跑 |
| 并发 | I/O 密集用异步（`asyncio.gather`/`Promise.all`/`CompletableFuture.allOf`），CPU 密集用多进程 |
| 内存 | 大数据集流式/分批处理，及时释放 |
| 清理 | 临时文件固定命名 + try/finally 清理，禁止无限累积 |
| 数据库 | 大表必须分页，合理使用索引 |
| 异步任务 | 状态持久化到 Redis/DB，必须有超时控制 |

## 缓存策略

任何缓存引入必须经用户明确同意。流程：识别瓶颈 -> 请求确认 -> 用户同意 -> 添加 -> 验证效果。

## 检查清单

- 重量级资源是单例？支持增量/断点续传？
- 批量操作？大文件流式？临时文件有清理？
- 异步任务有超时和状态持久化？
