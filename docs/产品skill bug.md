/product Skill Bug Report：总路线图 PRD 场景下 S6/S7/S8 流程不适配
                                          
  问题概述                     
                                   
  /product 流程假设所有 PRD 产出物都包含 UNIT（开发级闭环功能），但总路线图 PRD 的可验收单元是 Phase（阶段级交付门禁），不产出 UNIT。导致 S6/S7/S8 顺序错误、S11 评审校验失配、S12 完成校验失败。
                                
  复现条件                     
                                
  当用户用 /product 编制的 PRD 属于以下场景时触发：
  - 产出物是总路线图 / 架构演进路线图 / 多阶段战略规划
  - PRD 产出模型为"总路线图 + 各 Phase 独立 PRD（JIT 编制）"                                                                                                                                            
  - Phase（P0~P4）在 S3 成功判据中已定义，不是 S8 从 UNIT 分组得来                                                                      
  - 具体 UNIT 在各 Phase 独立 PRD 编制时才产生                                                                                                                                                          
                                                                                                    
  问题详情                                                                                                                                                                                              
                                                                                                    
  问题 1：S6/S7/S8 顺序错误                                                                                                                                                                             
                                                                                                                                                                                                        
  当前流程：                    
  S5 → S6(UNIT拆解) → S7(AC定义) → S8(Phase规划) → G1 → S9~S12                                                                                                                                          
                                                                                                    
  实际需要：                              
  S5 → S8(Phase规划) → G1 → S9~S12（跳过S6/S7）
                                                                                                                                                                                                        
  原因：                       
  - 标准 feature PRD 的逻辑：需求 → 拆 UNIT → 定 AC → UNIT 分组到 Phase                                                                                                                                 
  - 总路线图 PRD 的逻辑：需求 → 定节奏（Phase 规划）→ 每个 Phase 开工前才拆 UNIT                                                                                                                        
  - S6/S7 的产出（UNIT + AC）在总路线图中不存在，S8（Phase 规划）才是总路线图的核心产出                                                                                                                 
                                                                                                                                                                                                        
  问题 2：S11 评审 reviewer prompt 假设存在 UNIT                                                                                                                                                        
                                                                                                                                                                                                        
  references/prd-reviewer-prompt.md 中的 R 检查项包含：                                             
  - UNIT 闭环性校验             
  - AC 可验证性校验             
  - UNIT 标题必须是功能名                                                                                                                                                                               
                                                                                                                                                                                                        
  总路线图没有 UNIT，reviewer 会产出无意义的 FAIL。                                                                                                                                                     
                                                                                                                                                                                                        
  问题 3：S12 completion_check.sh 假设存在 units/ 目录                                                                                                                                                  
                                                                                                                                                                                                        
  完成校验包含：                                                                                                                                                                                        
  - units/ 目录存在且非空                                                                                                                                                                               
  - 每个 UNIT 有闭环定义 + AC                                                                                                                                                                           
  - AC 格式 AC-U{N}-{N}                                                                                                                                                                                 
                                                                                                                                                                                                        
  总路线图不产出 units/ 目录，校验必然 FAIL。                                                                                                                                                           
                                                                                                                                                                                                        
  问题 4：G1 对齐确认位置不对                                                                       
                                
  当前：G1 在 S6 之后（UNIT 拆解后对齐）                                                                                                                                                                
  总路线图需要：G1 在 S8 之后（Phase 规划后对齐）                                                                                                                                                       
                                                                                                                                                                                                        
  原因：总路线图的"理解对齐"是让用户看到"需求 + 节奏"的完整画面，而非"需求 + UNIT 清单"。
