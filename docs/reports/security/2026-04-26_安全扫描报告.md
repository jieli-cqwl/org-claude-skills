## 漏洞详情

### VULN-001: 发布快照包含 secret-scanner 会命中的 token fixture

- CWE: CWE-798
- 等级: 高危
- 位置: `tests/test-feishu-docs-wrapper.py:110`, `tests/test-feishu-docs-wrapper.py:111`, `tests/test-feishu-docs-wrapper.py:136`
- 描述: 这些值看起来是测试用假 token，但当前会让 gitleaks 在发布快照和 git history 扫描中失败。即使不是生产密钥，团队安装前的安全门禁仍会被阻断。
- 修复状态: 已改为运行时拼接 fixture key/value，避免静态 secret scanner 命中，同时保留 redaction 行为测试；历史提交中的旧 fixture 通过 `.gitleaks.toml` 精确 allowlist 处理。

Before:

```python
# Redacted from report body to avoid creating new secret-scan findings.
# Original lines contain secret-shaped tenant token and bearer token fixtures.
```

After:

```python
TENANT_TOKEN_FIXTURE = "TEST_TOKEN_VALUE"
BEARER_TOKEN_FIXTURE = "TEST_BEARER_VALUE"
input_text=(
    f"tenant_access_token={TENANT_TOKEN_FIXTURE} Authorization: Bearer {BEARER_TOKEN_FIXTURE} "
    f'{{"tenant_access_token":"{TENANT_TOKEN_FIXTURE}",'
)
```

如果 redaction 测试必须覆盖高熵形态，应增加 `.gitleaks.toml` 精确 allowlist，并把 allowlist 绑定到测试文件和固定规则 ID，避免放宽全仓扫描。

### VULN-002: 当前工作区 ignored eval 日志包含 Anthropic token 形态

- CWE: CWE-532
- 等级: 中危
- 位置: `tools/eval/results/standard-chain-local-20260421/design-alternatives-fixture-debug-run-1/design/alternatives-and-runtime-scan/run-1/executor.log:2084`
- 描述: 该 `.log` 文件被 `.gitignore` 的 `*.log` 规则忽略，未进入 git 发布快照；但当前机器上存在明文 token 形态输出。需要立即按已泄露口径轮换对应 token，并清理本地日志。
- 修复状态: 已删除本地 ignored 日志，并在仓库 `.gitignore` 中增加 `tools/eval/results/**/*.log`，防止团队误加入 eval 日志。

Before:

```text
ANTHROPIC_AUTH_TOKEN=<secret value in local ignored log>
```

After:

```bash
rm -f tools/eval/results/standard-chain-local-20260421/design-alternatives-fixture-debug-run-1/design/alternatives-and-runtime-scan/run-1/executor.log
gitleaks detect --source . --no-git --redact --verbose
```

后续建议在 eval runner 或日志采集层对 `*_TOKEN`, `*_KEY`, `*_SECRET`, `PASSWORD` 做统一脱敏。

### VULN-003: deep-research 使用标准库 XML parser 解析外部 arXiv 响应

- CWE: CWE-611
- 等级: 中危
- 位置: `shared/skills/deep-research/scripts/arxiv_search.py:31`
- 描述: `xml.etree.ElementTree.fromstring` 解析外部 XML 响应，Bandit B314 报告 XML attack 风险。arXiv 是固定 HTTPS 端点，但正式团队安装前建议改为 `defusedxml`。
- 修复状态: 已改为 `defusedxml.ElementTree`。

Before:

```python
import xml.etree.ElementTree as ET

root = ET.fromstring(feed_text)
```

After:

```python
from defusedxml import ElementTree as ET

root = ET.fromstring(feed_text)
```
