# 业务流程

## BF-1: 用户登录认证流程
**起点**: 用户访问系统，未登录状态  
**终点**: 用户获得会话，进入系统主界面

**流程步骤**:
1. 用户打开登录页面
2. 用户输入账号和密码
3. 系统验证账号是否存在
4. 系统验证密码是否匹配
5. 系统创建会话并返回会话标识
6. 用户携带会话标识访问系统功能

**异常分支**:
- 账号不存在 → 提示"账号或密码错误"
- 密码不匹配 → 提示"账号或密码错误"
- 会话创建失败 → 提示"系统繁忙，请稍后重试"

## BF-2: 会话保持与验证流程
**起点**: 用户已登录，携带会话标识访问功能  
**终点**: 系统验证会话有效性，允许或拒绝访问

**流程步骤**:
1. 用户请求携带会话标识
2. 系统从 Redis 查询会话信息
3. 系统检查会话是否过期（30分钟无操作）
4. 会话有效 → 允许访问并刷新过期时间
5. 会话无效 → 返回 401，要求重新登录

## BF-3: 用户登出流程
**起点**: 用户已登录，主动登出  
**终点**: 会话失效，用户返回登录页

**流程步骤**:
1. 用户点击登出按钮
2. 系统删除 Redis 中的会话记录
3. 系统返回登出成功
4. 前端清除本地会话标识，跳转登录页
