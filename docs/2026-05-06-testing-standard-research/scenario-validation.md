# 测试执行规范场景验收

验收结论：PASS。

本验收用于判断 `shared/reference/测试规范.md` 是否能指导新人和 AI 做测试决策。判断口径：每个样本都能输出测试依据、测试义务、测试层级、交付证据和交付结论；无法闭合的证据进入阻塞、缺陷处理或用户明确风险接受。

## 样本 1：纯业务规则变更

变更样本：优惠计算新增 VIP 折扣上限，订单金额、会员等级和优惠券组合会影响最终价格。

依据提取：成功标准是 VIP 折扣不超过上限；验收标准包括普通用户、VIP 用户、优惠券叠加、金额边界和非法金额处理；影响范围包括价格计算调用方和结算展示。

测试义务：覆盖正常路径、边界路径、失败路径和调用方回归；新增可观察行为先形成会失败的自动化测试；新增或变更的业务逻辑、分支判断和错误处理路径，行覆盖率与分支覆盖率目标为 90% 以上。

测试层级：纯业务规则、分支判断、边界计算和错误处理用单元测试证明；结算展示调用方用功能测试或回归测试证明。

交付证据：完成前重新执行单元测试、覆盖率报告和调用方回归命令；未覆盖边界必须记录风险和补充证据。

交付结论：目标行为、边界路径、失败路径、覆盖率和回归对象全部闭合后才能交付。

## 样本 2：API + DB 变更

变更样本：新增 `POST /orders`，请求成功后写入订单表并返回订单编号。

依据提取：成功标准是合法请求创建订单并持久化；验收标准包括请求方法、路径、参数、鉴权、幂等、响应字段、状态码、错误结构和副作用结果；真实依赖包括数据库、鉴权和服务模块协作。

测试义务：接口契约变更必须验证完整契约；数据库落库和模块协作必须由真实依赖、测试环境、本地容器或已验证集成路径证明；Mock 不替代真实依赖验收。

测试层级：请求校验和错误分支可用单元测试；接口行为用功能测试；落库、鉴权和服务协作用集成路径证明。

交付证据：完成前重新执行 API 测试、真实数据库或本地容器集成测试、覆盖率报告和契约回归；只看到 Mock 测试通过不能交付。

交付结论：接口契约、真实落库、错误结构、幂等和鉴权拒绝路径全部闭合后才能交付。

## 样本 3：UI 功能变更

变更样本：结算页新增优惠码输入、错误提示和提交按钮禁用逻辑。

依据提取：成功标准是用户输入有效优惠码后价格刷新，输入无效优惠码后看到可感知错误提示；影响范围包括表单、按钮状态、价格展示和提交流程。

测试义务：用户可见功能必须验证输入、操作、预期结果和实际结果；页面变更触发键盘可操作、焦点可见、语义可识别、对比度合格和错误提示可感知验证。

测试层级：组件内状态和边界用功能测试；目标用户完成优惠码应用的主路径用最短真实流程或 E2E 证明；高风险失败路径在功能测试无法证明时补充 E2E。

交付证据：完成前重新执行 UI 功能测试、可访问性检查、主路径验证记录和必要截图或录屏；人工验收只在当前工具无法稳定复现时使用，并记录不自动化原因。

交付结论：有效码、无效码、禁用状态、错误提示、主路径和可访问性义务全部闭合后才能交付。

## 样本 4：缺陷修复

变更样本：用户快速重复点击支付按钮会生成两笔支付请求。

依据提取：历史缺陷和原复现步骤是测试依据；成功标准是重复点击只产生一次支付请求，重复请求得到可预期反馈。

测试义务：修复缺陷时，用原复现步骤或对应回归用例证明原错误结果不再出现；只看到新结果正确，不足以证明缺陷已修复。

测试层级：防重复提交状态用功能测试；支付请求幂等和服务端处理用集成路径证明；跨页面入口、服务处理和外部支付依赖时用最短真实流程验证。

缺陷裁决：若可能产生重复扣款，严重程度为 `S0 阻断` 或 `S1 严重`；若阻断当前上线或客户交付，优先级为 `P0 立即处理`。

交付证据：完成前重新执行原复现步骤、回归用例、幂等集成测试和相关支付路径验证；缺陷记录包含触发条件、实际结果、预期结果、影响范围、严重程度、优先级和复验方式。

交付结论：原错误不再出现、回归通过、严重程度和优先级完成裁决后才能交付。

## 样本 5：性能 / 安全相关变更

变更样本：订单搜索接口新增复杂筛选条件，并允许按用户输入的关键词查询。

依据提取：专项风险包括性能、安全和数据访问风险；成功标准包括搜索结果正确、响应时间达标、权限边界不被绕过、敏感字段不泄露。

测试义务：高频查询和数据库查询变更必须记录变更前后指标或明确目标阈值；鉴权、权限、输入处理、敏感数据和 SQL 执行相关变更必须验证授权路径、拒绝路径、非法输入和敏感输出处理。

测试层级：查询条件组合和错误处理用单元测试；搜索接口行为用功能测试；数据库查询计划、权限边界和真实数据访问用集成路径或测试环境证明。

交付证据：完成前重新执行性能基准、查询计划检查、安全用例、接口测试、覆盖率报告和真实依赖验证；指标退化必须说明原因、影响范围和用户明确的处理决定。

交付结论：结果正确性、变更前后指标、目标阈值、授权路径、拒绝路径、非法输入和敏感输出全部闭合后才能交付。

## 有效性判断

这 5 类样本覆盖纯逻辑、接口契约、真实依赖、用户路径、缺陷修复、非功能风险和交付裁决。每个样本都能从规范中推导出测试依据、测试义务、测试层级、交付证据和交付结论，因此本次优化在场景验收层面有效。
