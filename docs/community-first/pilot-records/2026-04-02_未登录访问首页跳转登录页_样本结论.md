# 2026-04-02 未登录访问首页跳转登录页 样本结论

日期：`2026-04-02`  
样本类型：`community-first 试点模拟样本`

## 结论

- 结论：`GO`
- 结论范围：`适合作为首周第二条轻量样本`
- 是否建议继续扩大到同类需求：建议

## 为什么这条样本通过

1. 用户意图明确
2. 成功标准单一
3. 变更点集中在路由守卫或页面入口判断
4. 可以在不引入复杂权限体系的前提下完成

## 这条样本的边界

本轮只覆盖：

- 未登录
- 访问首页
- 跳转登录页

不覆盖：

- 登录后回跳原页面
- 多角色权限守卫
- 会话刷新

## 对试点的价值

这条样本补充了首个登录成功样本没有覆盖的“访问保护”场景，能帮助团队判断：

- 小需求是否会在路由层自然扩边
- `brainstorming` 是否能及时识别边界膨胀

## 后续动作

- 在真实业务仓库中优先验证最小 route guard 实现
- 若需求提出方坚持增加回跳策略，应切换到更正式链路
