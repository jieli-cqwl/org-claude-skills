# 2026-04-01 首周样本池

日期：`2026-04-01`  
适用周期：`2026-04-01 ~ 2026-04-07`

## 选样原则

本周只选下面这类样本：

- 单次可收口
- 低到中风险
- 需求边界清晰
- 不需要正式 Phase 级排期

## 推荐样本类型

建议从下面 5 类里选 3-5 个真实需求：

1. 单页面或单组件行为调整
2. 单一接口字段补充或轻量改造
3. 文档与实现一体的小需求
4. 小型交互优化或状态修正
5. 单个脚本/工具的小幅增强

## 本周不纳入试点池

- 核心模型切换
- 核心 API 大改
- 复杂数据迁移
- 高风险兼容 / 安全 / 性能需求
- 明显需要 `/product -> /design -> /test-design -> /tech-lead -> /project-manager` 的需求

## 建议样本配比

- `2` 个实现类小需求
- `1` 个文档或工具类需求
- `1-2` 个边界模糊样本

说明：

- 边界模糊样本不是为了强行走轻量链，而是为了观察误路由和退回标准链是否顺畅

## 每个样本的最低产物

每个样本至少产出：

1. 一份单样本记录
2. 关键命令摘要
3. 最终结论：
   - `PASS`
   - `FAIL`
   - `转标准链`

## 周目标

- 样本总数：`3-5`
- 成功样本：`至少 2`
- 误路由样本：允许出现，但必须记录
- 转标准链：允许出现，但必须有明确超界原因

2. `未登录访问首页跳转登录页`
3. `登录失败停留登录页并提示错误`
