# Standard-chain Product-to-delivery Field Decision Matrix

Status: implementation input v1.

Scope: fields that affect the `product-director -> product-manager -> tech-lead baseline -> delivery-owner -> signoff` chain. Historical reports, raw transcripts, eval results, and archived docs are evidence inputs only; they are not active contract surfaces.

Evidence used for this draft:

- `contracts/standard-chain.yaml`
- `contracts/standard-chain-field-consumption.yaml`
- `shared/skills/lib/contracts/shared-core.schema.json`
- Scoped artifact schemas and templates under `shared/skills/{product-manager,design,test-design,tech-lead,developer,verify,review,qa,consistency-audit,fix,delivery-owner}/`
- Canonical pilot fixtures under `tests/fixtures/standard-chain-pilots/login-homepage-pilot` and `tests/fixtures/standard-chain-pilots/feedback-thanks-pilot`
- Active validators and checks under `shared/skills/*/scripts/`, `tools/community/`, and `tests/test-standard-chain-*.sh`

Grouped rows are intentional. A grouped row is valid only when all listed paths share the same owner, consumer, write stage, read stage, source of truth, verification method, failure behavior, and recovery owner. Implementation must split any grouped row before editing schemas or scripts when a member path has different semantics.
