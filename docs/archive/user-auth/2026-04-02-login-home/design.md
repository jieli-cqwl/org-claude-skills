# Design — login-home

创建日期: 2026-04-02

## Why

用户登录成功后停留在当前页，导致下一步操作路径不明确。需要将登录成功流转到首页，减少额外点击和认知中断。

## Scope

- 范围内: 登录成功后统一跳转首页；保留登录失败提示。
- 不做: 角色差异化首页路由；埋点体系重构。

## Approach

在登录成功分支统一调用路由跳转至首页。保留现有鉴权逻辑与异常处理，不改变登录 API 契约。

## Alternatives Considered

| 方案 | 优势 | 劣势 | 结论 |
|------|------|------|------|
| 前端登录成功后跳首页 | 改动小、回归面可控 | 依赖前端状态正确 | 采用 |
| 后端返回目标路由 | 可做动态策略 | 需要改协议和多端适配 | 暂不采用 |

## Key Decisions

- D1: 登录成功后由前端路由层跳首页。
  - 理由: 最小改动，兼容现有接口。

## Success Criteria

- 登录成功后 1 秒内进入首页。
- 登录失败时保留原错误提示，不发生错误跳转。
