# org-claude-skills v1.0.1 发布说明

发布日期：2026-03-25

## 版本目标

在保持安装安全的前提下，进一步消除历史噪音并确保可恢复：
- 不遗留旧版本受管垃圾文件。
- 不因清理动作造成误删或不可恢复。

## 主要变更

1. 安装阶段新增“旧版本遗留受管文件”自动清理。  
2. 新增 `.org-pruned-manifest` 元数据，记录被清理条目。  
3. 卸载阶段支持恢复 `.org-pruned-manifest` 中条目（依赖备份映射）。  
4. 系统测试新增“清理 + 卸载恢复”场景。

## 风险与兼容性

- 向后兼容：是。  
- 元数据新增：是（`~/.claude/.org-pruned-manifest`、`~/.codex/.org-pruned-manifest`）。  
- 首次升级到 `1.0.1` 时会提示旧环境缺失该文件并自动补齐。

## 升级命令

```bash
cd ~/org-claude-skills
bash install.sh --target all --force --check quick
```

## 验证命令

```bash
bash tests/run-all.sh
cd ~/.claude
codex exec --json "List all currently available skills by exact name only, one per line, no extra text."
```
