# org-claude-skills v1.2.2 发布说明

## 核心变更

1. `codex-doc-review` 与 `codex-doc-reviewer` 改为 Claude 专属能力，不再安装到 Codex。
2. 修复 `~/.codex/AGENTS.md` 标题渲染错误，Codex 运行入口不再显示 `# CLAUDE.md`。
3. 清理共享入口文案和高频 reference 中的 Claude-only 噪音，减少 Codex 运行面误导。
4. 新增 `tests/test-platform-runtime-noise.sh`，对平台噪音做回归门禁。
5. 新增平台噪音巡检报告与 hotfix 修复记录，便于团队追溯。

## 升级命令

```bash
cd ~/org-claude-skills
git pull --rebase
bash install.sh --target all --force --merge-hooks --check full
bash tools/dev/probe-runtime-capabilities.sh ~/org-claude-skills
```

## 验收重点

- `bash tests/run-all.sh` 通过
- `bash install.sh --target all --force --merge-hooks --check full` 通过
- `~/.codex/AGENTS.md` 首行是 `# AGENTS.md`
- Codex skill 列表中不再出现 `codex-doc-review`
- `bash tests/test-platform-runtime-noise.sh` 通过

## 已知边界

- Claude：
  - 可依赖全局 hooks 与 skill-local Stop hook
  - 保留 `codex-doc-review` 作为 Claude 调用 Codex CLI 的跨模型文档审查能力
- Codex：
  - 可依赖 skills 与 agent 委派
  - 不把 hooks 当成强保障
  - 对 `completion_check.sh` 以显式脚本执行为准
