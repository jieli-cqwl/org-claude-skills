# org-claude-skills v1.2.1 发布说明

## 核心变更

1. Codex 运行时 skill 文档改为真实能力口径，移除误导性的 frontmatter `hooks:`。
2. 对带 `scripts/completion_check.sh` 的 Codex skill，统一改为“结束前显式执行脚本”，不再伪装成自动 hook 保障。
3. 新增 `tests/test-codex-skill-adapter.sh`，防止 Codex dead hooks 配置回归。
4. 新增运行时真实性探针脚本：
   - `tools/dev/probe-claude-capabilities.sh`
   - `tools/dev/probe-codex-capabilities.sh`
   - `tools/dev/probe-runtime-capabilities.sh`
5. 新增团队运行验收 SOP：`docs/runtime-acceptance-sop.md`。
6. 更新发布检查与回滚校验，正式纳入运行时真实探针。
7. 新增 Claude 代理兼容说明：`docs/claude-proxy-compatibility.md`。

## 升级命令

```bash
cd ~/org-claude-skills
git pull
bash install.sh --target all --force --merge-hooks --check full
bash tools/dev/probe-runtime-capabilities.sh ~/org-claude-skills
```

## 验收重点

- `bash tests/run-all.sh` 通过
- `bash install.sh --target all --force --merge-hooks --check full` 通过
- `bash tools/dev/probe-runtime-capabilities.sh ~/org-claude-skills` 无 `[FAIL]`
- Codex 安装产物不再保留误导性的自动 hooks 口径
- Claude / Codex 的真实运行边界在文档中显式可见
- Claude 走 LiteLLM / OpenAI 兼容代理时，subagent 模型别名前置条件已显式文档化

## 已知边界

- Claude：
  - 可依赖全局 hooks 与 skill-local Stop hook
  - 若走自定义代理，需确认代理兼容 `claude-*` 模型名
- Codex：
  - 可依赖 skills 与 agent 委派
  - 不把 hooks 当成强保障
  - 对 `completion_check.sh` 以显式脚本执行为准
