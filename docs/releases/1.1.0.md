# v1.1.0 发布说明

## 摘要

本版本完成统一仓库的第二阶段治理：安装状态外置、运行目录零安装噪音、旧 `.claude` git 退役闭环、运行期完整性门禁补齐。

## 主要变更

1. 安装状态与备份统一外置到 `~/.org-skills-state/`。
2. `.claude` / `.codex` 运行目录不再保留 `.org-*` 与 `.org-backups/`。
3. 修复重复 `--force` 覆盖安装后的恢复基线问题，卸载可回到用户原始文件。
4. 新增 `tools/migration/retire-dot-claude.sh`，用于归档旧 `.claude` repo-only 文件并退役 `.git`。
5. 新增 `claude/CLAUDE.md` 统一入口文件。
6. 新增 `reference/review-iteration-protocol.md` 全局协议，修复 design/review/test-design 的局部引用断裂。
7. 新增 `tests/test-runtime-integrity.sh`，校验运行期引用完整性与零元数据噪音。

## 升级命令

```bash
cd ~/org-claude-skills
git pull
bash install.sh --target all --force --check full
```

如需退役旧 `~/.claude` git：

```bash
bash tools/migration/retire-dot-claude.sh --claude-dir ~/.claude
```

## 回滚

```bash
cd ~/org-claude-skills
bash install.sh --uninstall --target all
```

详见：`docs/rollback-sop.md`
