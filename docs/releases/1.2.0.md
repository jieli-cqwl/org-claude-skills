# org-claude-skills v1.2.0 发布说明

## 核心变更

1. 仓库重构为 `shared/` 单一真源，Claude / Codex 只保留薄适配层。
2. 删除手工维护的 `claude/skills`、`codex/skills`、`claude/reference`、`claude/rules`、`claude/agents` 等重复源目录。
3. 安装器改为从共享源码渲染双端运行目录，Claude 生成 `CLAUDE.md`，Codex 生成 `AGENTS.md`。
4. Codex 运行期不再依赖 `~/.claude` 路径，补齐 `~/.codex/hooks/lib/common.sh`。
5. 新增单一真源结构测试与 `docs/capability-matrix.md` 能力矩阵。
6. 新增 `tools/dev/probe-codex-hooks.sh` 与 `docs/codex-hooks-support.md`，对 Codex 全局 hooks 支持边界给出可复现实测结论。

## 升级影响

- 团队维护入口正式收口到 `shared/` 与平台适配层。
- 运行期安装命令不变，仍使用：

```bash
cd ~/org-claude-skills
bash install.sh --target all --force --check full
```

## 验收重点

- `bash tests/run-all.sh` 通过
- `bash install.sh --target all --force --check full` 通过
- Codex 安装产物中不再出现 `~/.claude` 运行时依赖
- 仓库中不再保留双份共享源树
