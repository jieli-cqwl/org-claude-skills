### ADR-005: 密码哈希算法选型
状态: Accepted
背景: 需选择密码哈希算法。bcrypt 是成熟方案但依赖 C 扩展编译；argon2 是更新标准但同样需要编译依赖；passlib 提供统一接口可切换后端。
决策: 选择 bcrypt（通过 passlib[bcrypt] 包装）。
理由: 1) bcrypt 是 OWASP 推荐的成熟方案，10-50 人内网不需要 argon2 的抗 GPU 优势；2) passlib 提供 verify/hash 统一接口，未来切换算法只改配置；3) bcrypt 的 pip 预编译 wheel 覆盖主流平台（macOS/Linux/Windows），实际编译问题风险低。
用户确认: bcrypt 成熟够用，passlib 包装提供灵活性 — 共创步骤 5
备选方案:
| 方案 | 优势 | 劣势 | 淘汰原因 |
|------|------|------|---------|
| argon2-cffi | 更强抗 GPU/ASIC | 编译依赖更重、社区文档较少 | 内网场景不需要抗 GPU |
| hashlib.pbkdf2_sha256 | 纯 Python 无编译依赖 | 安全强度低于 bcrypt | 不推荐用于密码存储 |
后果: 正面：成熟、预编译 wheel 广泛 / 负面：极端环境可能需要编译 / 约束：requirements.txt 必须包含 passlib[bcrypt]
