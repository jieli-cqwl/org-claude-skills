### ADR-004: 前端路由守卫方案
状态: Accepted
背景: 需要在前端拦截未登录用户访问受保护路由，同时处理 token 过期场景。有 React Router loader、高阶组件包裹、axios 拦截器三种实现路径。
决策: 选择 React Router ProtectedRoute 高阶组件 + axios 响应拦截器双层防护。
理由: 1) ProtectedRoute 解码 JWT payload 的 exp 字段判断过期（客户端第一道防线）；2) axios 拦截器捕获 401 响应做兜底（服务端第二道防线）；3) 双层确保即使客户端时钟偏差，服务端仍能拦截。
用户确认: 双层防护合理，exp 字段判断是标准做法 — 共创步骤 5
备选方案:
| 方案 | 优势 | 劣势 | 淘汰原因 |
|------|------|------|---------|
| 仅 React Router loader | 集中管理 | 无法处理 API 调用时 token 过期 | 不覆盖 API 调用场景 |
| 仅 axios 拦截器 | 统一 API 层处理 | 路由跳转时无法预检 | 用户先看到页面再被踢出，体验差 |
后果: 正面：双层覆盖全场景 / 负面：两处 token 检查逻辑需保持一致 / 约束：token 过期判断统一使用 JWT exp claim 解码
