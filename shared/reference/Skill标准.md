# Skill 标准

Skill 的存在价值只有两种：承载真实专业流程，或稳定执行用户确认的偏好。不符合的 Skill 增加触发入口、上下文成本和维护负担。

## 最低标准

| 维度 | 判断 |
| --- | --- |
| 触发准确 | description 清楚说明何时使用、何时不使用，能与相邻 Skill 分流 |
| 结果更好 | with-skill 比 without-skill 在目标行为上可观测地更好 |
| 成本合理 | context 开销和维护成本低于它带来的收益 |
| 职责真实 | 对应真实专业流程或用户确认的稳定偏好 |
| 不可替代 | 基础模型或相邻 Skill 无法稳定覆盖同一职责 |

## 评估方式

- **能力增益**：with-skill vs without-skill 对比；`with_avg >= 4.0` 且 `uplift >= 1.0` 支持 retain。
- **偏好保真**：偏好锚点命中率；`fidelity >= 0.80` 且无关键锚点遗漏支持 retain。
- **组合价值**：同时承载专业流程和稳定偏好时，两侧证据须同时成立。

## 生命周期信号

| 信号 | 条件 |
| --- | --- |
| retain | 能力增益或偏好保真有经验证据支持，成本可接受 |
| optimize | 价值方向成立但证据不足，或存在明显优化点 |
| retire | 无增益证据、偏好失真、可被替代或成本 > 收益 |
