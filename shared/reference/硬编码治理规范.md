# 硬编码治理规范

## 分类与存放

| 优先级 | 类型 | 存放位置 |
|--------|------|----------|
| P0 | 敏感配置（密钥/密码/Token） | 环境变量 / `.env`（不入库） |
| P1 | 用户消息 | `runtime_config/messages.yaml` |
| P2 | 业务常量 | `constants.py` / `{module}/constants.py` |
| P3 | 枚举/状态 | `enums.py` / `{module}/enums.py` |

## 常量分层决策

- 仅当前文件 -> 文件顶部就近定义，UPPER_CASE
- 同模块多文件 -> `{module}/constants.py`
- 跨模块共享且语义稳定、属于公共契约 -> `src/constants.py`
- 跨模块导入检测：`from src.{module_a}.constants import X` 出现在 module_b -> 先判断是否为稳定共享语义；否则优先调整依赖方向、保留边界内重复或放到概念拥有方

## 命名规范

- 全局：`{DOMAIN}_{NAME}`（如 `API_VERSION`）；模块：`{MODULE}_{NAME}`（带前缀防冲突）
- 有限集合 + `==` 比较 -> 枚举；数值/字符串 -> 常量

## 膨胀阈值

- `constants.py` > 200 行 -> 触发拆分检查，按领域、所有权、稳定性和依赖方向拆分
- 单模块 > 100 行 -> 检查是否存在稳定共享语义；不能只因行数提升全局

## 导入规范

- 禁止跨模块导入模块级常量；是否提升全局按稳定共享语义判断；禁止 `from xxx import *`
