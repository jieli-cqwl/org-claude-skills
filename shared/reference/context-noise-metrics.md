# Context Noise Metrics

> 类型：reference（共享度量口径，非执行规范）。
> 用途：固定 sub agent 降噪效果的统一样本边界、指标定义和阶段门槛。
> 指标只用于复算与对比，不决定是否启用 sub agent。

## 口径原则

- 所有阶段统一使用同一组 `M1~M6`，不允许各自重新命名。
- 统计对象是“一个主阶段的一次完整运行”，不是单个草稿文件。
- 指标只反映可复算的上下文噪音变化，不承担 Gate 裁决职责。

## 样本边界

| 维度 | 定义 |
|------|------|
| 样本 | 某一主阶段的一次完整运行 |
| 起点 | 主 Agent 第一次读取该阶段 required inputs |
| 终点 | 该阶段最终工件冻结，或 terminal report 写完 |
| 采样对象 | 主 Agent、sub agent 草稿、最终工件、回收记录 |
| 不计入对象 | 与该阶段无关的旁支探索、未进入回收合同的临时对话 |

## 基线规则

| 场景 | 基线要求 |
|------|----------|
| `tech-lead / delivery-owner` | 必须是同阶段、未启用该阶段 sub agent 改造的历史样本，且 Task 数量差异 `<= 3` 或相对差异 `<= 30%` |
| `product / design / test-design` | 必须是同阶段、未启用该阶段 sub agent 改造的历史样本，且 scope item / AC 数量差异 `<= 30%` |
| 基线缺失 | 只能判定 `INCONCLUSIVE`，不得硬判 `PASS` |

## 指标定义

| 指标 | 定义 | 计算方式 |
|------|------|----------|
| `M1` | 主 Agent 手工维护字段数 | 主 Agent 在最终工件中亲自编写或重写的有效字段数 |
| `M2` | 同一事实重复回写次数 | 同一事实被主 Agent 重复手工回写到多个草稿或最终工件的次数 |
| `M3` | 首轮稳定问题数 | 首轮完整独立审查中的稳定问题数 |
| `M4` | 收敛轮次 | 从第一版完整工件到 `PASS / FAIL 已修正` 的收敛轮次 |
| `M5` | 草稿冲突回退数 | 由草稿冲突直接触发的上游回退、整包重做或整版废弃次数 |
| `M6` | 草稿采用字段数 | 最终工件中被直接采用或仅做轻微修正后采用的草稿字段数 |

## 统一判定

| 判定 | 触发条件 |
|------|----------|
| `PASS` | 阶段 Gate 与 completion check 全部通过，且 `M1 / M2` 相比基线下降，`M3 / M4` 不高于基线，`M5 = 0` |
| `FAIL` | 命中任何 fail-fast，或 Gate / completion check 被破坏 |
| `INCONCLUSIVE` | 未命中 fail-fast，但样本不足、基线不足或指标没有形成明确结论 |

## 阶段门槛

- 任一阶段要宣布 `PASS` 并写回主 skill，至少需要 `3` 个正式样本。
- `3` 个样本都必须有可比基线。
- 任一样本命中 fail-fast，阶段直接判定 `FAIL`。
- 少于 `3` 个样本、缺基线、或指标分布没有形成方向性，只能判定 `INCONCLUSIVE`。

## 记录要求

| 字段 | 要求 |
|------|------|
| 样本阶段 | 必填，写明主阶段名称 |
| 样本编号 | 必填，唯一 |
| M1~M6 | 必填，固定列名，不得改名 |
| 基线来源 | 必填，写明对照样本 |
| 采集人 | 必填，写明主 Agent 或 reviewer 责任人 |
| 证据锚点 | 必填，支持独立复算 |
| 记录模板 | 固定为 `./templates/metrics-log-template.md` |
