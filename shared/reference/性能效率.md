# 性能效率

> 触发条件：涉及批量处理、并发设计、缓存引入、大数据集操作时读取。
> MUST 级约束已收录在 `rules/代码规范.md` 性能约束章节。本文件提供实践指南。

## 核心要点

| 维度 | 建议 |
|------|------|
| 增量 | 优先增量处理，记录已处理状态，避免全量重跑 |
| 并发 | I/O 密集用异步（`asyncio.gather`/`Promise.all`/`CompletableFuture.allOf`），CPU 密集用多进程 |
| 内存 | 大数据集流式/分批处理，及时释放 |
| 清理 | 临时文件固定命名 + try/finally 清理 |
| 数据库 | 合理使用索引，避免 N+1 查询 |
| 异步任务 | 状态持久化到 Redis/DB |

## 缓存策略

流程：识别瓶颈 -> 请求用户确认 -> 用户同意 -> 添加 -> 验证效果。

## 检查清单

- 重量级资源是单例？支持增量/断点续传？
- 批量操作？大文件流式？临时文件有清理？
- 异步任务有超时和状态持久化？
