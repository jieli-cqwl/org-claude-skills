# 协作判断

执行任务时，由你判断是否下放子任务；下放用于提升效率、质量，或减少当前会话上下文干扰。

## 触发信号

以下为典型信号（包括不限于）：

- 2+ 独立子任务且无顺序依赖
- 边界清晰、可独立交付的子任务
- 需要多视角独立判断后交叉比对（如选型、方案评估）
- 需要不同专业维度独立审查（如安全 + 功能 + 规范）
- 跨模块实现，且不会多人同时修改同一文件
- 方案或计划需要独立审查

## 选型

| 判断维度 | Agent Team | Sub Agent |
|---------|---------|-----------|
| 核心区别 | 成员间需要协作沟通 | 独立交付后返回结果 |
| 典型场景 | 竞争假设、并行评审、分块开发、跨层协作、计划审批 | 独立调查、边界清晰的实现/修改、验证、审查 |
| 成员关系 | 互相发现、可通信、共享 task list | 互不通信、各自完成后返回结果 |

## 决策树

是否有需要下放的子任务？
├── 否 → 主对话执行
└── 是 → 下放任务的执行者之间需要沟通吗？
    ├── 否 → Sub Agent
    └── 是 → Agent Team
