# 系统调试

调试以确认根因和可复验证据为目标。

HARD-GATE: 完成 Observe 之前禁止改代码。

Observe → Hypothesize → Test 只用于定位根因；不得借调试名义继续实现、切换方案或宣称完成。Fix 仅在根因已确认且不改变原目标时进入；否则先向用户报告并等待裁决。

## 四阶段

| 阶段 | 做什么 |
| --- | --- |
| 1. Observe | 复现问题，或证明当前环境不可复现；记录错误信息、环境、输入、时间线和最小触发条件 |
| 2. Hypothesize | 基于观察事实提出可证伪假设和证伪条件；证据已唯一指向根因时，记录该证据链 |
| 3. Test | 从证据支持度最高的假设开始，一次只变一个变量，用实验结果支持或排除假设 |
| 4. Fix | 定义能失败的回归验证并做最小修复，保留错误可观测性；重新执行原复现和影响范围验证，核心或共享变更扩大验证面 |
