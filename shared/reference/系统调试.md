# System Debugging

Debugging proves the causal path with reproducible evidence, not symptom disappearance.

Start with Observe. Until Observe captures the failure, do not edit code, switch designs, enter Fix, or claim completion. Treat errors, failed assertions, logs, and tool explanations as symptoms until evidence links them to the causal path.

For cross-boundary failures, observe the real input, output, state change, timing, and error surface at each relevant boundary before naming any single-point exception as the root cause. Browser/backend auth and session short checks should preserve the boundary list: Cookie, CORS, proxy/header, JWT or session, cache/load balancing, and clock skew. Use independent perspectives only to expose blind spots and challenge hypotheses; merge judgment by evidence, not vote.

Observe → Hypothesize → Test is diagnosis. Move to Fix only when the root cause is confirmed, the fix stays inside the current goal, and a regression proof would fail before the fix.

## Four Stages

| Stage | Required Action |
| --- | --- |
| 1. Observe | Reproduce the failure, or prove why the current environment cannot reproduce it. Record the exact input, path, environment, expected result, observed result, timeline, and smallest known trigger. |
| 2. Hypothesize | Build falsifiable hypotheses from observed facts. Include alternative explanations and the result that would change the current judgment. |
| 3. Test | Run the experiment that best distinguishes the competing hypotheses. State the expected result before running it, change one variable at a time, and record which hypothesis is confirmed, excluded, or still unknown. |
| 4. Fix | Create or identify a regression proof that would fail before the fix. Make the smallest fix, preserve observability, then rerun the original reproduction and affected-scope verification. |

## Root Cause Standard

A confirmed root-cause claim must name:

- the failing behavior
- the causal mechanism
- the concrete code location, runtime boundary, dependency, or decision owner
- the evidence linking cause to symptom
- the alternatives excluded by evidence

If the causal path is not proven, report the current evidence, unresolved hypotheses, blocked dependency, remaining uncertainty, and next decision needed.
