# Fact Scan Template

> 用途：`Fact Scan` 类 sub agent 的唯一模板源。
> 约束：只记录事实、证据和未决项，不写最终裁决。

## 统一 schema

| 字段 | 固定值 / 填写要求 |
|------|-------------------|
| `agent_kind` | 固定为 `fact_scan` |
| `current_judgment_type` | 固定为 `fact` |
| `decision_state` | 固定为 `候选` |
| `input_boundary` | 必填，引用下方 `## 输入边界` |
| `evidence_anchor` | 必填，引用下方 `## 证据锚点` |
| `unresolved_item` | 条件必填，引用下方 `## 未决项` |
| `forbidden_action` | 必填，引用下方 `## 禁止越权项` |

## 输入边界

| 来源类型 | 来源 | 说明 |
|------|------|------|
| required_input | | 当前阶段必须读取的上游输入 |
| upstream_artifact | | 已存在的上游工件 |

## 禁止越权项

- 不得给出最终裁决。
- 不得冻结编号或 Gate。
- 不得把推断写成事实。

## 回收备注

- 只保留可回链的事实锚点。
- 若事实无法采证，明确写入未决项，不要模糊跳过。
