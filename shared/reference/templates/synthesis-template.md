# Synthesis Template

> 用途：`Synthesis` 类 sub agent 的唯一模板源。
> 约束：只汇总既有状态和证据，不新增 Gate 或风险接受结论。

## 统一 schema

| 字段 | 固定值 / 填写要求 |
|------|-------------------|
| `agent_kind` | 固定为 `synthesis` |
| `current_judgment_type` | 固定为 `summary` |
| `decision_state` | 固定为 `待裁决` |
| `input_boundary` | 必填，引用下方 `## 输入边界` |
| `evidence_anchor` | 必填，引用下方 `## 证据锚点` |
| `unresolved_item` | 条件必填，引用下方 `## 未决项` |
| `forbidden_action` | 必填，引用下方 `## 禁止越权项` |
