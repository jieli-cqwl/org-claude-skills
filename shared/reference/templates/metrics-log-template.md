# Metrics Log Template

> 用途：`M1~M6` 统一记录模板。
> 约束：所有阶段使用同一列名，确保结果可独立复算。

## 样本信息

| 字段 | 值 | 说明 |
|------|----|------|
| 阶段 | | 主阶段名称 |
| 样本编号 | | 唯一编号 |
| 起点 | | 主 Agent 第一次读取 required inputs 的时刻 |
| 终点 | | 最终工件冻结或 terminal report 写完的时刻 |
| 基线来源 | | 对照样本 |
| 采集人 | | 主 Agent 或 reviewer 责任人 |

## 指标记录

| 指标 | 定义 | 当前值 | 基线值 | 差异 | 采集方式 | 证据锚点 |
|------|------|--------|--------|------|----------|----------|
| M1 | 主 Agent 手工维护字段数 | | | | | |
| M2 | 同一事实重复回写次数 | | | | | |
| M3 | 首轮稳定问题数 | | | | | |
| M4 | 收敛轮次 | | | | | |
| M5 | 草稿冲突回退数 | | | | | |
| M6 | 草稿采用字段数 | | | | | |

## 阶段判定

| 判定 | 结果 | 说明 |
|------|------|------|
| PASS | | Gate 与 completion check 全部通过，且 `M1 / M2` 下降、`M3 / M4` 不高于基线、`M5 = 0` |
| FAIL | | 命中 fail-fast，或 Gate / completion check 破坏 |
| INCONCLUSIVE | | 少于 `3` 个样本、基线不足，或指标没有形成明确结论 |

## 备注

- `M1~M6` 必须写入固定列名表格。
- `PASS / FAIL / INCONCLUSIVE` 的口径必须与 `context-noise-metrics.md` 完全一致，不得自定义。
- 少于 `3` 个正式样本或任一样本缺少可比基线，只能写 `INCONCLUSIVE`。
- 若某项无法采集，直接说明原因，不要空着假装完成。
