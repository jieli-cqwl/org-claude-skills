# 测试断言边界

## Skill Markdown 测试边界

- `shared/skills/**/*.md`、`references/*.md`、`projections/*.md` 的自然语言正文不得由 shell 测试用 `assert_present` 或 `assert_absent` 锁定具体措辞。
- Skill 行为由 `shared/skills/*/evals/evals.json`、真实运行链路或专用验证脚本证明；正文文案可演化，只要行为证据仍成立。
- shell 测试只守机器契约：文件存在、路径、脚本名、命令参数、manifest、JSON/YAML 字段、schema、hook 注册、stdout/stderr、legacy 路径不复活。
- 命令形状不豁免整句文案；只能断言命令 token，例如脚本名或参数，不能锁定中文前缀、完整行或解释性短语。
- 新增低信号 Markdown 断言必须改为行为 eval、schema/fixture 断言、脚本输出断言或删除；不得通过扩大 baseline 绕过。

## 门禁

- `tools/community/check_test_signal_assertions.py` 负责拦截新增低信号 Markdown 正文断言。
- `tests/fixtures/test-assertion-boundary/low-signal-prose-assertions.baseline` 只冻结历史遗留项；新增命中必须修正测试设计。
