# UX 评审框架

## Nielsen 十原则

| # | 原则 | 检查方法 |
|---|------|---------|
| 1 | 系统状态可见性 | 操作后是否有即时反馈？加载/成功/失败是否可感知？ |
| 2 | 系统与现实匹配 | 术语是否用户能理解？图标是否符合认知习惯？ |
| 3 | 用户控制与自由 | 误操作能否撤销？是否有明确的返回/退出路径？ |
| 4 | 一致性与标准 | 同类操作是否统一？是否遵循平台惯例？ |
| 5 | 错误预防 | 高风险操作是否有确认？输入是否有实时校验？ |
| 6 | 识别而非回忆 | 用户是否需要记忆信息才能操作？选项是否可见？ |
| 7 | 灵活性与效率 | 是否为熟练用户提供快捷方式？频繁操作是否高效？ |
| 8 | 简约设计 | 界面是否只展示必要信息？有没有无关内容干扰？ |
| 9 | 错误恢复 | 错误提示是否说明原因和解决方法？ |
| 10 | 帮助与文档 | 复杂功能是否有上下文帮助？新功能是否有引导？ |

## 格式塔视觉原则

- 接近性：相关元素靠近分组，无关元素足够间距
- 相似性：同类操作统一视觉样式
- 闭合性：信息分组有明确视觉边界
- 连续性：阅读流和操作流自然顺畅
- 共同区域：逻辑相关内容在同一视觉区域内

## 交互定律速查

| 定律 | 阈值 | 检查方法 |
|------|------|---------|
| 工作记忆容量 | 单步信息项 ≤ 7 | 数字段/选项/步骤数 |
| 选择负担 | 核心操作选项 ≤ 5 | 数选项数量 |
| 操作效率 | 移动端触摸目标 ≥ 44×44px | 量测按钮/链接尺寸 |
| 响应时间 | 反馈 ≤ 100ms；加载提示 ≤ 1s | 计时 |
