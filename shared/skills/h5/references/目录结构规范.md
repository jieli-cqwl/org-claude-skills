# 目录结构规范

## 项目结构

```
project-root/
├── api/
│   ├── index.js              # 统一导出
│   └── modules/              # tenant.js / contract.js / common.js
├── components/               # 公共组件（comp-xxx/comp-xxx.vue）
├── pages/
│   ├── main/                 # home/HomePage.vue, login/LoginPage.vue
│   ├── {模块}/               # list/ detail/ form/ components/
│   └── common/               # webview/ 等公共页面
├── store/
│   ├── Index.js              # 统一导出
│   └── modules/              # Common.js / User.js / {业务}.js
├── static/
│   ├── images/icons/         # SVG 优先
│   ├── images/tabbar/        # TabBar 图标（normal + selected）
│   ├── images/empty/         # 空状态图
│   └── fonts/
├── utils/                    # request.js / storage.js / validate.js / format.js / platform.js
├── uni_modules/              # uni-ui / z-paging
├── App.vue / main.js / manifest.json / pages.json / uni.scss
```

## 命名规范

| 类别 | 规则 | 示例 |
|------|------|------|
| 页面目录 | 小写 | `tenant/list/` |
| 页面文件 | PascalCase | `TenantList.vue` |
| 公共组件目录 | `comp-` 前缀 | `comp-popup/comp-popup.vue` |
| Store 文件 | PascalCase | `Common.js` |
| Store 导出 | `use{模块}Store` | `useCommonStore` |
| API 文件 | 小写模块名 | `tenant.js` |

## 组件存放

| 类型 | 位置 |
|------|------|
| 全局公共 | `/components/comp-xxx/` |
| 模块私有 | `/pages/{模块}/components/` |
| 页面子组件 | 与页面同级 `components/` |

## 禁止

- 组件无 `comp-` 前缀
- 组件 `.vue` 不放独立目录
- 页面文件用 kebab-case（应 PascalCase）
- 工具函数合并到单文件
