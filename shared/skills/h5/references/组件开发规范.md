# 组件开发规范

## 命名规则

格式：`comp-{功能}[-{变体}]`

| 组件名 | 用途 |
|--------|------|
| `comp-popup` | 底部弹窗 |
| `comp-popup-tips` | 提示弹窗 |
| `comp-popup-picker` | 选择器弹窗 |
| `comp-form-configure` | 动态表单 |
| `comp-dropmenu-new` | 下拉筛选 |
| `comp-notice` | Toast/Loading |
| `comp-empty` | 空状态 |
| `comp-card-info` | 信息卡片 |

禁止：无前缀（`Popup`）、下划线（`comp_popup`）、驼峰（`compPopup`）、后缀（`popup-comp`）

## easycom 配置

```json
{ "easycom": { "custom": { "^comp-(.*)": "@/components/comp-$1/comp-$1.vue" } } }
```

使用时无需 import，直接 `<comp-popup />`。

## 组件结构

```vue
<template>
  <view class="comp-xxx" :class="{ 'is-disabled': disabled }">
    <slot name="header" />
    <view class="comp-xxx__content">{{ content }}</view>
    <slot name="footer" />
  </view>
</template>
<script setup lang="ts">
interface Props { content?: string; disabled?: boolean }
const props = withDefaults(defineProps<Props>(), { content: '', disabled: false })
const emit = defineEmits<{ click: [value: string] }>()
</script>
<style lang="scss" scoped>
.comp-xxx { &.is-disabled { opacity: 0.5; pointer-events: none; } &__content { } }
</style>
```

## BEM 样式命名

- Block: `.comp-xxx`
- Element: `&__header / &__content / &__footer`
- Modifier: `&--large`
- State: `&.is-visible / &.is-active / &.is-disabled`

## CSS 属性顺序

定位 → 盒模型 → 视觉 → 文字 → 其他

## Props 命名

| 类型 | 前缀 | 示例 |
|------|------|------|
| 布尔值 | is/has/can/show | `isDisabled` `showHeader` |
| 回调 | on | `onConfirm` |
| 数组 | 复数 | `options` `items` |

## Emits 命名

| 场景 | 事件名 |
|------|--------|
| 值变化 | `change` / `update:modelValue` |
| 确认 | `confirm` / `submit` |
| 取消 | `cancel` / `close` |
| 选择 | `select` / `pick` |

## 插槽

- 具名插槽配合 `v-if="$slots.header"` 条件渲染容器
- 作用域插槽传递 `:item` `:index`
