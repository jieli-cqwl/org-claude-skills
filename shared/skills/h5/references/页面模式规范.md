# 页面模式规范

## 列表页 — z-paging

```vue
<z-paging ref="pagingRef" v-model="list" @query="queryList">
  <template #top>
    <comp-dropmenu-new :options="filterOptions" @change="onFilterChange" />
  </template>
  <view v-for="item in list" :key="item.id" class="list-item" @tap="goDetail(item.id)">
    ...
  </view>
  <template #empty><comp-empty text="暂无数据" /></template>
</z-paging>
```

- `queryList(pageNo, pageSize)` → `pagingRef.value?.complete(res.records)` 成功 / `complete(false)` 失败
- 筛选变更 → 合并参数 → `pagingRef.value?.reload()`

## 表单页 — comp-form-configure

```vue
<comp-form-configure ref="formRef" :formItemMap="formItemMap" :formModel="formModel" />
<view class="footer-btn safe-area-bottom">
  <button :loading="submitting" @tap="handleSubmit">提交</button>
</view>
```

- `formItemMap` 定义每个字段的 `{ type, label, required, placeholder, options? }`
- 提交前 `await formRef.value?.validate()`
- 底部按钮固定定位 + `safe-area-bottom`

## 多步骤表单

- Pinia store 管理 `step / maxStep / 各步骤数据`
- 主页面 `v-if="store.step === N"` 切换步骤组件
- `onUnmounted` 调用 `store.reset()`

## 详情页

- `loading` → `uni-load-more` / 内容切换
- `onMounted` 从 `getCurrentPages().pop()?.options` 取参数
- 底部操作栏 `footer-btn safe-area-bottom`

## Tab 页面

- Tab 栏 + swiper 联动
- `currentIndex = computed(() => tabs.findIndex(...))`
- swiper `@change` 同步 `currentTab`

## 页面目录结构

```
pages/{模块}/
├── list.vue / detail.vue / form.vue
├── components/     # 步骤组件等
└── stores/         # 模块私有 store
```
