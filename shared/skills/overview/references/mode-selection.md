# overview 模式选择

## AskUserQuestion 选项

- `串行概览（更快）`：更快收口，适合结构清晰或只需快速入门
- `分层 agent team 概览（更全面）`：覆盖更多证据面，适合复杂仓库或文档缺口明显的项目
- `默认推荐自动继续` 不允许；必须等待用户确认后再继续

## 触发信号

| 信号 | 更适合模式 |
|------|-----------|
| 单语言、入口清晰、README 完整 | 串行概览（更快） |
| 多语言或多框架 | 分层 agent team 概览（更全面） |
| 入口文件、配置文件或文档分散 | 分层 agent team 概览（更全面） |
| 用户只要快速起步路径 | 串行概览（更快） |

## 推荐话术

- 先总结预扫描信号：项目规模、语言/框架数量、入口和文档完整度
- 再明确推荐：`我建议使用 {模式}，因为 {信号摘要}。`
- 同时说明代价：串行更快；分层 agent team 更全面但需要更多调度和汇总
- 最后 AskUserQuestion 等待用户确认后再继续

## 停止条件

- 用户未确认前禁止进入模块识别、agent 派发或文档生成
- 用户改变模式选择时，主代理按新模式重新组织后续步骤
