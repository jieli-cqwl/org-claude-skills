# 兼容入口说明

此文件保留给旧路径引用，不再承载具体报告模板。

请先读取 `references/report-presentation-framework.md`，再按 `presentation_profile` 选择对应头部模板：
- `decision` → `research-decision-header-template.md`
- `understanding` → `research-understanding-header-template.md`
- `audit` → `research-audit-header-template.md`

若尚未确定 `presentation_profile`，先按 `research_mode` 的默认路由收敛，不能把旧路径兼容入口直接当作 `audit` 默认模板。

完整报告结构为：
1. 呈现模式头部
2. 调研模式正文
3. `research-shared-audit-appendix-template.md` 共享审计附录
