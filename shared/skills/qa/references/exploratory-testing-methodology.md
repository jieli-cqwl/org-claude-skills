# 探索性测试方法论

> 供 /qa 验证-D 阶段引用。发现脚本化测试遗漏的问题。

## 1. 基于风险的探索策略

### 高风险区域（优先探索）

| 区域 | 风险原因 |
|------|---------|
| 新增功能 | 首次实现，可能考虑不周 |
| 重构的模块 | 行为可能发生变化 |
| 复杂业务逻辑 | 条件分支多，容易遗漏 |
| 用户输入处理 | 攻击面大 |
| 并发操作 | 竞态条件难以预测 |
| 状态转换 | 非法转换可能未防御 |
| 边界交互 | 模块间数据传递可能丢失 |

### 风险评估矩阵

| 可能性\影响 | 高影响 | 中影响 | 低影响 |
|------------|--------|--------|--------|
| 高可能性 | 立即探索 | 优先探索 | 探索 |
| 中可能性 | 优先探索 | 探索 | 选择性 |
| 低可能性 | 探索 | 选择性 | 跳过 |

## 2. 会话式探索测试

### 章程模板

```
探索章程 #N
- 目标: [要探索的功能/区域]
- 关注: [具体风险/假设]
- 时间盒: [预计时间]
- 方法: [探索策略]
```

### 执行规则

| 规则 | 说明 |
|------|------|
| 时间盒 | 每个章程设定时间限制，到时收结 |
| 记录一切 | 每个操作和观察都记录 |
| 偏离探索 | 发现线索时可以偏离章程追踪 |
| 发现分类 | Bug / 疑问 / 观察 / 改进建议 |

## 3. 常见探索方向

### 3a. 异常输入组合

| 策略 | 示例 |
|------|------|
| 多字段同时违规 | 所有必填字段同时为空 |
| 类型混搭 | 数字字段传中文、布尔字段传数组 |
| 超大输入 | 单字段 10MB 文本 |
| 特殊字符 | emoji、零宽字符、RTL 字符、NULL 字节 |
| 编码攻击 | URL 编码、HTML 实体、Unicode 转义 |

### 3b. 操作顺序变化

| 策略 | 示例 |
|------|------|
| 跳步 | 不执行步骤 2 直接执行步骤 3 |
| 重复 | 同一操作连续执行 5 次 |
| 逆序 | 先删除后创建 |
| 并发 | 两个请求同时操作同一资源 |
| 快速切换 | 在操作完成前发起下一个操作 |

### 3c. 状态边界

| 策略 | 示例 |
|------|------|
| 空系统 | 数据库完全为空时的行为 |
| 满载 | 大量数据时的分页/搜索/排序 |
| 初始化前 | 服务刚启动未完全就绪时请求 |
| 资源耗尽 | 磁盘满/内存高/连接池满 |

### 3d. 中断恢复

| 策略 | 示例 |
|------|------|
| 网络中断 | 请求中途断网 |
| 超时 | 长操作超过超时限制 |
| 服务重启 | 操作中途重启服务 |
| 部分失败 | 批量操作中部分成功部分失败 |

## 4. 发现记录格式

```
### 发现 #N
- **探索方向**: [属于哪个章程/方向]
- **操作**: [具体执行的操作]
- **观察**: [看到的现象]
- **期望**: [应该是什么行为]（如适用）
- **严重度**: Critical / Major / Minor / Observation
- **复现步骤**: [精确复现命令]
- **分类**: BUG / QUESTION / OBSERVATION / SUGGESTION
```
