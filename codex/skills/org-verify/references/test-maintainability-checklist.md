# 测试可维护性检查清单

> 供 verify Phase 2C 检查 7 引用。评估测试代码的长期可维护性。

## 1. 命名清晰度

| 检查项 | PASS 标准 | FAIL 信号 |
|--------|---------|---------|
| 描述行为 | 测试名描述"做什么+什么条件+什么结果" | `test1`、`testFunction`、`testEdgeCase` |
| 无实现细节 | 测试名不引用内部方法名 | `testCallsValidateMethod` |
| 可读性 | 读名字就知道测什么 | 需要读代码才知道测什么 |

## 2. AAA 模式遵循

| 检查项 | PASS 标准 | FAIL 信号 |
|--------|---------|---------|
| 结构清晰 | Arrange / Act / Assert 三段明显 | 代码混杂，无法区分 |
| 单一 Act | 每个测试只有一个被测行为 | 一个测试调用多个被测方法 |
| 无 Assert 副作用 | Assert 段不执行额外操作 | Assert 中修改状态 |

## 3. 重复 Setup/Teardown

| 检查项 | PASS 标准 | FAIL 信号 |
|--------|---------|---------|
| 共享提取 | 3+ 个测试的相同 setup 已提取 | 大段复制粘贴的 setup |
| 局部 setup | 仅部分测试需要的 setup 在 describe 嵌套中 | 全局 beforeEach 做了仅部分测试需要的 setup |
| 清理配对 | 每个 setup 有对应 teardown | setup 了但没清理 |

## 4. 过度断言

| 检查项 | PASS 标准 | FAIL 信号 |
|--------|---------|---------|
| 聚焦行为 | 每个测试断言一个行为的结果 | 一个测试 10+ 行断言 |
| 不断言无关属性 | 仅断言与被测行为相关的字段 | 断言整个对象的所有字段 |
| 不断言实现细节 | 断言外部可观察结果 | 断言内部调用次数/顺序 |

## 5. 隐式依赖

| 检查项 | PASS 标准 | FAIL 信号 |
|--------|---------|---------|
| 顺序无关 | 任意顺序执行测试结果相同 | 调换顺序后测试失败 |
| 状态隔离 | 每个测试有独立数据 | 测试 B 依赖测试 A 创建的数据 |
| 无全局可变状态 | 不依赖全局变量/单例状态 | 修改全局变量后未恢复 |

## 6. 参数化适用性

| 检查项 | PASS 标准 | FAIL 信号 |
|--------|---------|---------|
| 重复模式识别 | 3+ 个仅输入/输出不同的测试已参数化 | 多个近乎相同的测试手动复制 |
| 参数化可读性 | 参数化测试的描述清晰 | `test.each` 但无有意义的描述 |
