# 路由规范

## 路径命名规则

```
pages/{模块}/{功能}/{PascalCase文件名}
```

| 类型 | 路径示例 |
|------|---------|
| 模块首页 | `pages/tenant/home/TenantHome` |
| 列表页 | `pages/tenant/list/TenantList` |
| 详情页 | `pages/tenant/detail/TenantDetail` |
| 表单页 | `pages/tenant/form/TenantForm` |
| 公共页 | `pages/common/webview/WebviewPage` |

## 导航 API

| 方法 | 用途 |
|------|------|
| `uni.navigateTo` | 保留当前页跳转 |
| `uni.redirectTo` | 关闭当前页跳转 |
| `uni.navigateBack({ delta })` | 返回 |
| `uni.switchTab` | 切换 Tab |
| `uni.reLaunch` | 关闭所有页跳转 |

## 参数传递

| 方式 | 适用场景 |
|------|---------|
| URL query（`?id=123`） | 简单参数，接收用 `onLoad(options)` |
| `eventChannel` | 复杂对象，`success` 回调 `emit` / 接收页 `getOpenerEventChannel().on()` |
| Pinia store | 多步骤流程 |

## 返回刷新上一页

```typescript
// 方式一：事件总线
uni.$emit('refreshTenantList')
uni.navigateBack()
// 上一页 onMounted: uni.$on('refreshTenantList', reload)
// 上一页 onUnmounted: uni.$off('refreshTenantList')

// 方式二：onShow（慎用）
```

## 路由守卫

- 白名单页面直接跳转，非白名单检查 token
- 无 token → `reLaunch` 到登录页，携带 `redirect` 参数
- 权限检查：`store.permissions.includes(pageCode)`

## 分包

```json
{
  "subPackages": [{ "root": "pages-tenant", "pages": [...] }],
  "preloadRule": { "pages/main/home/HomePage": { "network": "all", "packages": ["pages-tenant"] } }
}
```

分包页面路径以 root 开头：`/pages-tenant/list/TenantList`
