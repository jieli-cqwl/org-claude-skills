# 最佳实践

## 防抖与防重复提交

- 搜索输入用 `debounce(fn, 500)`（项目 `utils/debounce.ts`）
- 表单提交用 `useSubmit` composable：loading 守卫 + try/finally

## 键盘处理

- `uni.onKeyboardHeightChange` 动态设置 `paddingBottom`
- 输入框自动聚焦延迟 300ms（避免页面动画冲突）：`setTimeout(() => autoFocus.value = true, 300)`

## 安全区域适配

```scss
.safe-area-bottom {
  padding-bottom: calc(20rpx + env(safe-area-inset-bottom));
}
```

系统信息：`uni.getSystemInfoSync().safeArea`

## 条件编译

```vue
<!-- #ifdef H5 -->    H5 专用
<!-- #ifdef MP-WEIXIN -->  微信小程序专用
<!-- #ifndef H5 -->   非 H5
```

JS/SCSS 同理，用 `// #ifdef` / `/* #ifdef */`

## 权限处理

`uni.getSetting` → `uni.authorize` → 失败引导 `uni.openSetting`

## 请求封装

| 约定 | 值 |
|------|-----|
| 成功码 | `code === 0` |
| Token 过期码 | `40100` → `reLaunch` 到登录页 |
| Header | `Authorization: Bearer {token}` |
| API 模块化 | `api/{模块}.ts` 导出对象，每个方法调用 `request<T>()` |

## 性能优化

| 技术 | 用法 |
|------|------|
| 图片懒加载 | `<image lazy-load />` |
| 虚拟列表 | `z-paging :use-virtual-list="true"` |
| 分包加载 | `pages.json` 的 `subPackages` + `preloadRule` |

## 调试

- 条件日志：`process.env.NODE_ENV === 'development'` 控制输出
- error 级别始终输出
