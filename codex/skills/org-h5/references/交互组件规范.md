# 交互组件规范

## 弹窗系列

### comp-popup（基础弹窗）

| Prop | 类型 | 默认 | 说明 |
|------|------|------|------|
| visible | boolean | false | 显示控制 |
| position | string | 'bottom' | top/bottom/center/left/right |
| round | boolean | true | 圆角 |
| closeOnClickOverlay | boolean | true | 遮罩关闭 |

事件：`@close`

### comp-popup-tips（确认弹窗）

Props: `title / content / confirmText / cancelText / showCancel`
事件：`@confirm / @cancel`

### comp-popup-picker（选择器弹窗）

Props: `options: [{label, value}] / defaultValue / multiple`
事件：`@confirm(selected) / @cancel`

## comp-dropmenu-new（下拉筛选）

```typescript
const menuOptions = [{
  key: 'status', title: '状态', type: 'single', // single | multiple
  options: [{ label: '全部', value: '' }, ...]
}]
```

事件：`@change(params)` — params 为 `{ [key]: value }` 对象
配合 z-paging：`filterParams = params → pagingRef.value?.reload()`

## comp-empty（空状态）

预设 type：`data / network / search / message`
插槽：`#action`（自定义操作按钮）
网络错误：`@retry`

## 消息提示（uni 原生）

| 场景 | API |
|------|-----|
| 成功 | `uni.showToast({ title, icon: 'success' })` |
| 失败 | `uni.showToast({ title, icon: 'none' })` |
| Loading | `uni.showLoading({ title, mask: true })` → `uni.hideLoading()` |
| 确认 | `uni.showModal({ title, content, confirmColor: '#ED184E' })` |

## 操作反馈时序

| 操作 | 反馈 |
|------|------|
| 点击提交 | 按钮 loading + disabled |
| API 成功 | Toast → 1.5s 后 navigateBack |
| API 失败 | Toast 'none' |
| 删除 | Modal 确认 → 执行 → Toast |
| 网络错误 | comp-empty type="network" + 重试 |

## 动画时长

| 类型 | 时长 |
|------|------|
| Toast | 200ms ease |
| 弹窗进入 | 300ms ease-out |
| 弹窗退出 | 250ms ease-in |
| 页面切换 | 300ms ease |
