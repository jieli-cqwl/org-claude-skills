# UNIT-1: 查看项目角色权限

**优先级**: MVP

## 优先级依据
如果看不清当前权限，就无法判断后续调整是否正确，也无法形成安全的权限管理闭环。

## 背景
项目管理员当前需要找平台管理员手工改权限，且改完后不容易直接确认某个角色到底拥有什么资源权限。

## 需求描述
提供一个项目级权限查看能力，让项目管理员能查看自己有权管理的项目中，某个角色当前拥有哪些资源权限。

## 功能闭环定义
- 输入/触发: 项目管理员进入权限配置中心，并选择一个自己有权管理的项目和其中一个角色
- 核心行为: 系统读取该角色当前的资源权限映射并展示出来
- 可观察结果: 用户能直接看到该角色当前的权限状态，不需要再通过人工询问确认

## 验收标准

> AC 编号格式: `AC-U{UNIT序号}-{序号}`。

### 正常场景
- AC-U1-01: 项目管理员选择自己管理的项目与角色 → 页面展示该角色当前拥有的资源权限

### 异常场景
- AC-U1-02: 未被授权管理该项目的用户尝试查看该角色权限 → 系统拒绝访问且不暴露该项目权限数据

### 边界条件
- AC-U1-03: 目标项目当前没有可配置角色或权限为空 → 页面显示空状态而不是报错

## 业务规则（如有）

- 角色只指项目内角色，不是公司统一身份角色。
- 只有项目管理员可查看自己管理项目的权限状态。

## 依赖
- 依赖 UNIT: 无
- 依赖业务对象: 项目、角色、资源、权限映射
- 受影响方: 项目权限配置入口、权限校验读取链路

## 排除项
- 不做权限调整
- 不做变更记录查询
- 不做跨项目角色继承
- 不把角色树可视化作为本 UNIT 必做能力
