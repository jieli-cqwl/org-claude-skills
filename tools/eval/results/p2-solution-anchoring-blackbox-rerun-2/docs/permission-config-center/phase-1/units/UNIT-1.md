# UNIT-1: 查看角色当前权限

**优先级**: MVP

## 优先级依据
没有当前权限视图，后续调整会变成盲改，根问题无法被安全解决。

## 背景
项目管理员需要先知道某个角色当前到底拥有哪些资源权限，才能判断是否需要新增或移除。

## 需求描述
项目管理员进入某个项目内的角色权限页后，系统展示该角色当前拥有的资源权限状态，便于直接确认现状。

## 功能闭环定义
- 输入/触发: 项目管理员选择一个自己有管理权限的项目内角色并进入权限查看页
- 核心行为: 系统读取该角色当前权限集合并展示给用户
- 可观察结果: 页面显示角色对应的资源权限状态，用户能直接看清当前配置

## 验收标准

### 正常场景
- AC-U1-01: 选择一个可管理项目的角色并打开查看页 → 页面显示该角色当前的资源权限状态

### 异常场景
- AC-U1-02: 打开一个没有管理权限的项目角色页 → 系统拒绝展示可编辑信息并返回 403

### 边界条件
- AC-U1-03: 角色当前没有任何资源权限 → 页面仍显示角色信息和空状态，不报错

## 业务规则（如有）
- 仅展示项目管理员有权管理的项目内角色。
- 当前权限视图只做查看，不产生修改。

## 依赖
- 依赖 UNIT: 无
- 依赖业务对象: 项目、项目内角色、资源、权限集合
- 受影响方: 权限调整页、审计记录页

## 排除项
- 不包含新增、移除或保存修改。
- 不把角色树作为必做展示形态。
