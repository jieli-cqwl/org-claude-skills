结论：**必须回 product-director**，不能由 product-manager 继续直接改。

本 case 已触发 Director 门禁：

- **两个 Phase 可能合并**：这是 Phase 边界调整。
- **范围描述要改**：这是 scope / Director 锁定字段调整。
- 因此 PM 只能提出问题、影响和建议方案，**不能直接改写已锁定的 Phase / 范围基线**。

下一步：

1. PM 暂停修改锁定字段。
2. 整理变更请求：为什么要合并、影响哪些 Phase、范围变化是什么、对后续 PRD/UNIT/AC 的影响。
3. 回到 **product-director 重开 Director 共创链路**。
4. Director 重新确认并锁定 Phase 与范围后，再 handoff 给 product-manager 继续细化。
