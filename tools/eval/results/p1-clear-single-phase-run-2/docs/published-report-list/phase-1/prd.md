# Phase 1: 已发布周报基础浏览闭环

> 项目背景、约束与设计决策见 [brief.md](../brief.md)

## 阶段目标

交付一个最小但完整的浏览闭环：已登录员工进入系统后，可以直接查看按发布时间倒序排列的已发布周报，并通过基础分页继续浏览更早内容。

## 入口与出口条件

- 入口条件: Brief 审查通过
- 出口条件: 本阶段所有 UNIT QA 通过，且员工可以在系统内完成已发布周报的基础浏览
