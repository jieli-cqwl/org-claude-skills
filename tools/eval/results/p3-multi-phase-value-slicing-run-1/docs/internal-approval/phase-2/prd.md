# Phase 2: 审批状态通知增强

> 项目背景、约束与设计决策见 [brief.md](../brief.md)

## 阶段目标

在核心审批闭环稳定后，为关键状态变化补充主动通知能力，降低审批人和申请人的状态追问成本。

## 入口与出口条件

- 入口条件: Phase 1 完成
- 出口条件: 本阶段所有 UNIT QA 通过，且关键状态变化可通过企业微信被主动提醒
