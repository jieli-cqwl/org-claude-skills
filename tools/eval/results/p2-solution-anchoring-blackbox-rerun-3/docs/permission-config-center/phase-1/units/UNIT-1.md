# UNIT-1: 查看角色当前权限

**优先级**: MVP

## 优先级依据

如果看不到当前权限，项目管理员就无法确认现状，也无法判断后续权限调整是否真的生效，所以查看能力是最小闭环的起点。

## 背景

项目管理员经常需要先确认某个角色当前到底拥有哪些资源权限，避免在信息不清的情况下反复找平台管理员确认配置。

## 需求描述

支持项目管理员打开自己有权管理的项目中的某个角色，直接查看该角色当前有效的资源权限和数据范围。

## 功能闭环定义

- 输入/触发: 项目管理员进入某项目的角色权限页，并选择某个角色。
- 核心行为: 系统读取该角色当前有效的权限集合，并按当前状态展示。
- 可观察结果: 管理员可以直接看到当前角色拥有哪些资源权限、数据范围以及空状态信息。

## 验收标准

### 正常场景
- AC-U1-01: 项目管理员打开自己有权限管理的项目中的某个角色权限页 -> 页面展示该角色当前有效的资源权限和数据范围。

### 异常场景
- AC-U1-02: 项目管理员尝试打开自己无权管理的项目角色权限页 -> 系统返回 403，且不展示该项目的角色权限细节。

### 边界条件
- AC-U1-03: 目标角色当前没有任何权限 -> 页面仍可正常打开并显示空状态，不报错。

## 业务规则（如有）

- 仅展示项目管理员有权管理的项目范围内角色。
- 展示结果必须反映当前有效权限，而不是历史草稿或缓存猜测。

## 依赖

- 依赖 UNIT: 无
- 依赖业务对象: 项目角色、资源项、权限关系
- 受影响方: 项目角色查看页、权限校验链路

## 排除项

- 不做权限修改。
- 不做批量授权。
- 不做跨项目继承。
