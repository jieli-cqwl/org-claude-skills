# Phase 2: 企业微信通知

> 项目背景、约束与设计决策见 [brief.md](../brief.md)

## 阶段目标

在审批闭环已跑通的基础上，把审批结果主动通知到申请人，减少人工查询和线下追问。

## 入口与出口条件

- 入口条件: Phase 1 完成
- 出口条件: 本阶段所有 UNIT QA 通过
