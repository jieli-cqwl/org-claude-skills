# UNIT-3: 查看审批记录

**优先级**: MVP

## 优先级依据
没有记录查询，审批闭环就没有“可追踪”出口，无法解决当前的追踪问题。

## 背景
申请人和管理员都需要看到审批历史和当前状态，才能停止线下追问。

## 需求描述
提供审批记录查看能力，申请人能看自己的记录，管理员能看全量记录，记录中包含处理结果和驳回原因。

## 功能闭环定义
- 输入/触发: 申请人或管理员打开审批记录页
- 核心行为: 系统按权限查询并展示审批记录，包含提交人、审批人、时间、处理结果、当前状态和驳回原因
- 可观察结果: 用户能直接看到每笔申请的历史和当前状态，不需要线下追问

## 验收标准

### 正常场景
- AC-U3-01: 申请人打开自己的审批记录页 → 系统展示本人提交的记录和当前状态
- AC-U3-02: 管理员打开全量审批记录页 → 系统展示所有审批记录、处理人和处理时间

### 异常场景
- AC-U3-03: 无权限用户尝试查看他人审批记录 → 系统拒绝访问，并提示无权限

### 边界条件
- AC-U3-04: 记录为空时打开记录页 → 系统展示空状态，而不是报错

## 业务规则（如有）
- 记录必须展示提交人、审批人、时间和处理结果。
- 驳回原因在记录中可见。

## 依赖
- 依赖 UNIT: UNIT-1, UNIT-2
- 依赖业务对象: 审批申请、审批结果、审批记录
- 受影响方: 管理视图、后续统计报表

## 排除项
- 企业微信通知
- 统计报表
- 手工导出
