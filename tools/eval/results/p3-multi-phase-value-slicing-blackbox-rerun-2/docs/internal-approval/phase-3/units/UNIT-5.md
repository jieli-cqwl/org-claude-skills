# UNIT-5: 查看审批统计报表

**优先级**: 扩展

## 优先级依据
统计报表只是在审批闭环成熟后增加的管理分析能力，不影响核心审批流是否成立。

## 背景
管理员需要从审批记录中快速看出整体处理情况，而不是逐条翻记录。

## 需求描述
提供审批统计报表，让管理员能查看一定范围内的审批汇总结果。

## 功能闭环定义
- 输入/触发: 管理员打开统计报表并选择统计范围
- 核心行为: 系统汇总审批记录并展示统计结果
- 可观察结果: 管理员能直接看到审批总量、通过量、驳回量和待处理量等汇总信息

## 验收标准

### 正常场景
- AC-U5-01: 管理员选择时间范围并打开报表 → 系统展示该范围内的审批汇总结果
- AC-U5-02: 管理员查看报表明细 → 系统展示汇总值与可追溯的统计来源

### 异常场景
- AC-U5-03: 统计范围内无数据 → 系统展示空报表状态，不报错

### 边界条件
- AC-U5-04: 统计范围跨越多天或多周 → 系统仍按同一口径汇总并展示

## 业务规则（如有）
- 报表口径必须和审批记录口径一致。
- 统计结果必须能回溯到原始审批记录。

## 依赖
- 依赖 UNIT: UNIT-3
- 依赖业务对象: 审批记录、统计结果
- 受影响方: 管理分析视图、数据口径定义

## 排除项
- 实时大屏
- 自定义多维钻取
- 报表导出模板配置
