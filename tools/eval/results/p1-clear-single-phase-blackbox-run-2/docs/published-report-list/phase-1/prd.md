# Phase 1: 已发布周报列表浏览

> 项目背景、约束与设计决策见 [brief.md](../brief.md)

## 阶段目标

本阶段交付一个登录后可访问的已发布周报列表页，让内部员工能够按发布时间倒序分页浏览最近发布的周报，并在列表为空时获得明确提示。

## 入口与出口条件

- 入口条件: Brief 审查通过
- 出口条件: 本阶段唯一 UNIT QA 通过
