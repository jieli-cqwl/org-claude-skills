# Phase 1: 审批闭环可追踪

> 项目背景、约束与设计决策见 [brief.md](../brief.md)

## 阶段目标

本阶段交付内部审批系统的最小业务闭环：员工能够提交审批申请，审批人能够处理并给出通过或驳回结果，申请人与管理员能够查看审批记录和当前状态。该阶段单独上线后，就应解决“审批进度和结果不可追踪”的核心问题。

## 入口与出口条件

- 入口条件: Brief 审查通过
- 出口条件: 本阶段所有 UNIT QA 通过

## 功能需求（UNIT 索引）

| UNIT | 标题 | 闭环目标 | 优先级 | 依赖 | 定义文件 |
|------|------|----------|--------|------|----------|
| UNIT-1 | 提交审批申请 | 员工提交申请 -> 系统创建审批记录并进入待处理 -> 申请可被后续审批 | MVP | - | units/UNIT-1.md |
| UNIT-2 | 审批人处理申请 | 审批人对待处理申请执行通过或驳回 -> 系统更新审批结果 -> 当前状态可见 | MVP | UNIT-1 | units/UNIT-2.md |
| UNIT-3 | 查看审批记录 | 申请人或管理员查询申请记录 -> 系统返回状态与处理历史 -> 用户可追踪审批结果 | MVP | UNIT-1, UNIT-2 | units/UNIT-3.md |
