# Phase 2: 审批结果主动通知

> 项目背景、约束与设计决策见 [brief.md](../brief.md)

## 阶段目标

本阶段在 Phase 1 审批闭环稳定运行的基础上，新增审批结果主动触达能力。当审批状态变化时，相关人可以收到企业微信通知，从“需要主动查询”增强到“结果主动送达”。

## 入口与出口条件

- 入口条件: Phase 1 完成
- 出口条件: 本阶段所有 UNIT QA 通过
