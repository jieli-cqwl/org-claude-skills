# UNIT-5: 查看审批统计报表

**优先级**: 增强

## 优先级依据

统计报表用于增强管理观察能力，但不影响单笔审批闭环是否能运行，因此属于增强项。

## 背景

当审批记录稳定沉淀后，管理者希望从单笔追踪提升到整体观察，查看审批运行情况和处理结果分布。

## 需求描述

管理者需要能够查看审批统计报表，了解一定范围内的审批量和处理结果汇总，以辅助观察审批运行情况。

## 功能闭环定义

- 输入/触发: 管理者打开审批统计报表
- 核心行为: 系统基于已有审批记录汇总统计数据
- 可观察结果: 管理者看到可用于观察审批运行情况的统计结果

## 验收标准

> AC 编号格式: `AC-U{UNIT序号}-{序号}`（如 AC-U1-01），由 product 定义权威编号，UNIT 内唯一递增。

### 正常场景

- AC-U5-01: 管理者打开审批统计报表 -> 系统展示指定范围内的审批总量以及通过/驳回结果汇总

### 异常场景

- AC-U5-02: 无管理权限用户尝试查看审批统计报表 -> 系统拒绝访问，不展示统计内容

### 边界条件

- AC-U5-03: 当前统计范围内暂无审批记录 -> 系统仍展示报表页面，并明确提示暂无统计数据

## 业务规则（如有）

- 报表能力建立在已有审批记录之上。
- 本阶段只定义业务目标，不定义统计维度和刷新方式的技术实现。

## 依赖

- 依赖 UNIT: UNIT-1、UNIT-2、UNIT-3
- 依赖业务对象: 审批记录、审批结果
- 受影响方: 管理员

## 排除项

- 不定义报表的维度模型与刷新策略。
- 不定义导出、订阅、定时推送等扩展报表能力。
- 不把报表结果作为审批流程本身的前置条件。
