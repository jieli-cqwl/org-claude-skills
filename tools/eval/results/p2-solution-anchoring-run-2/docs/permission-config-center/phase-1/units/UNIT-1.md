# UNIT-1: 查看项目角色当前权限

**优先级**: MVP

## 优先级依据

如果项目管理员不能先看清某个项目角色当前拥有哪些权限，后续所有调整都会继续依赖人工解释现状，因此这是最小闭环的起点。

## 背景

当前权限现状分散在平台管理员和多个配置入口之间，项目管理员难以独立判断是否真的需要改动。

## 需求描述

提供一个项目级角色权限查看能力，让项目管理员能够针对某个自己有权管理的项目角色，直接看到当前已授权的资源权限状态。

## 功能闭环定义

- 输入/触发: 项目管理员进入某个项目的权限配置中心并选择一个项目内角色
- 核心行为: 系统读取该角色当前权限配置并按统一视图呈现
- 可观察结果: 用户能看到该角色当前拥有的资源权限；无权限用户会被明确拒绝

## 验收标准

> AC 编号格式: `AC-U{UNIT序号}-{序号}`（如 AC-U1-01），由 product 定义权威编号，UNIT 内唯一递增。

### 正常场景

- AC-U1-01: 已授权的项目管理员进入项目 A 的角色 R 权限页 → 页面展示角色 R 当前拥有的资源权限状态

### 异常场景

- AC-U1-02: 无项目 A 管理权限的用户访问角色 R 权限页 → 系统拒绝访问并展示明确的权限不足结果

### 边界条件

- AC-U1-03: 角色 R 当前没有任何资源权限 → 页面明确展示“暂无权限配置”，而不是空白或报错

## 业务规则（如有）

- 只允许查看当前用户有管理权限的项目角色。
- 展示的是当前生效权限状态，不展示未来计划中的权限变更。

## 依赖

- 依赖 UNIT: 无
- 依赖业务对象: 项目角色、资源权限配置
- 受影响方: 现有项目管理后台角色详情入口

## 排除项

- 不提供跨项目聚合查看。
- 不定义必须使用角色树或其他特定交互形态。
