# Phase 1: 项目级权限治理最小闭环

> 项目背景、约束与设计决策见 [brief.md](../brief.md)

## 阶段目标

交付一个项目管理员可独立使用的权限治理闭环：先看清项目角色当前权限，再完成一次常规新增或移除授权，最后能够追溯本次变更。

## 入口与出口条件

- 入口条件: Brief 审查通过
- 出口条件: 本阶段所有 UNIT QA 通过，且项目管理员不再依赖平台管理员解释现状或确认常规调整结果

## 功能需求（UNIT 索引）

| UNIT | 标题 | 闭环目标 | 优先级 | 依赖 | 定义文件 |
|------|------|----------|--------|------|----------|
| UNIT-1 | 查看项目角色当前权限 | 项目管理员进入项目角色权限页 → 系统展示当前权限状态 → 用户看清现状 | MVP | - | units/UNIT-1.md |
| UNIT-2 | 调整项目角色资源权限 | 项目管理员提交新增或移除授权 → 系统校验并保存变更 → 当前权限立即更新 | MVP | UNIT-1 | units/UNIT-2.md |
| UNIT-3 | 查询权限变更记录 | 项目管理员进入变更记录页 → 系统返回操作人/时间/差异 → 用户完成追溯 | MVP | UNIT-2 | units/UNIT-3.md |
