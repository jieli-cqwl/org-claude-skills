# Phase 1: 项目级权限查看、调整与追溯最小闭环

> 项目背景、约束与设计决策见 [brief.md](../brief.md)

## 阶段目标

本阶段交付项目级权限配置中心的最小业务闭环：让项目管理员先看清某个项目内角色当前拥有的资源权限，再在授权范围内完成常规新增/移除操作，并在操作后查询标准化变更记录。阶段边界限定在项目级角色权限，不覆盖跨项目继承、组织同步、复杂审批流，也不预设角色树或批量交互方案。

## 入口与出口条件

- 入口条件: Brief 审查通过
- 出口条件: 本阶段所有 UNIT QA 通过
