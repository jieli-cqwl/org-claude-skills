# Phase 1: 已发布周报列表页

> 项目背景、约束与设计决策见 [brief.md](../brief.md)

## 阶段目标

交付一个登录后可访问的已发布周报列表页，支持默认按发布时间倒序展示、每页 10 条、上一页/下一页翻页，以及列表为空时的明确提示。

## 入口与出口条件

- 入口条件: Brief 审查通过
- 出口条件: 本阶段唯一 UNIT QA 通过
