# Phase 2: 企业微信审批通知

> 项目背景、约束与设计决策见 [brief.md](../brief.md)

## 阶段目标

Phase 2 在不影响 Phase 1 核心审批闭环的前提下，把审批状态变化的结果推送到企业微信，让相关人不用再靠人工追问。

## 入口与出口条件

- 入口条件: Phase 1 完成
- 出口条件: Phase 2 所有 UNIT QA 通过
