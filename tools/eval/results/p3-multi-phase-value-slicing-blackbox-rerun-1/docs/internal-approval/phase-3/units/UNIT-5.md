# UNIT-5: 审批统计报表查看

**优先级**: 扩展

## 优先级依据
统计报表依赖稳定的审批数据沉淀，属于 Phase 1/2 之后的管理型扩展能力，不影响核心审批闭环成立。

## 背景
管理者需要知道审批总量、通过和驳回的整体情况，不能只靠单笔记录判断运行状态。

## 需求描述
管理者打开统计报表后，需要能查看审批汇总结果，并根据统计条件获得可读的管理视图。

## 功能闭环定义
- 输入/触发: 管理者进入统计报表入口并选择统计条件
- 核心行为: 系统汇总审批数据并生成统计报表
- 可观察结果: 页面展示统计结果，管理者能直接读取汇总信息

## 验收标准

> AC 编号格式: `AC-U5-{序号}`

### 正常场景
- AC-U5-01: 管理者选择一个统计条件后查看报表 → 系统展示审批总量、通过数量和驳回数量的汇总结果

### 异常场景
- AC-U5-02: 无权限用户访问统计报表 → 系统返回无权限结果，不展示统计内容

### 边界条件
- AC-U5-03: 统计条件下没有可汇总数据时 → 系统展示零状态或空状态，不报错

## 业务规则（如有）
- 统计结果必须与审批记录一致。
- 报表只面向管理视角，不替代单笔审批记录查询。

## 依赖
- 依赖 UNIT: UNIT-1、UNIT-2、UNIT-3
- 依赖业务对象: 审批记录、统计报表
- 受影响方: 管理者

## 排除项
- 企业微信通知
- 多级会签
- 报表导出与自定义图表配置
